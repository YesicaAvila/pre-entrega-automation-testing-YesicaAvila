El propósito del proyecto

## Automatizacion QA - Saucedemo

Este proyecto contiene casos de pruebas automatizadas para la plataforma Saucedemo (https://www.saucedemo.com/), con el objetivo de validar los flujos principales de la aplicacion mediante la interaccion con la interfaz de usuario.

Las tecnologías utilizadas

## Tecnologias usadas

- **Lenguaje:** Python
- **Framework de pruebas:** Selenium
- **Framework de pruebas:** Pytest
- **Navegador:** Google Chrome / Chrome
- **Control de versiones:** Git
- **Repositorio y colaboración:** Github
